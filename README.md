# 🎰 Tokio Slots

A high-performance, visually engaging Slot Machine web application built with **React**, **TypeScript**, and **GSAP**. Features a custom 3D-animated lever, physics-based reel rotations, and a responsive scaling system.

## 🚀 Features

- **GSAP Animations:** Realistic reel spinning with `back.out` easing and 3D lever physics using CSS perspective.
- **Dynamic Scaling:** Custom resolution-independent scaling system that maintains aspect ratio across all devices.
- **State Management:** Robust game logic handled by **Zustand**, including a full-state machine for spin cycles.
- **Atmospheric Soundscape:** Integrated `SoundManager` for spatial audio effects and background music.
- **Animated Background:** Parallax floating decorations using optimized React hooks and GSAP.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript
- **Animations:** GSAP (GreenSock), Framer Motion
- **State:** Zustand
- **Styling:** CSS3 (with Container Queries and CSS Variables)
- **Icons:** Custom SVG Assets

## 📦 Installation

1. Clone the repository: `git clone https://github.com/your-username/tokyo-slots.git`
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
